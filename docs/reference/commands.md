# Commands

Generated by `composer reference` from the public surface (ADR 0010). Do not edit.

## `kami:audit:prune`

Delete the Audit log events older than kami.audit.retention months

## `kami:bench`

Measure the server time of a page, from the page cache and rendered

- `[--user [USER]]`: Sign in with Digest as this user, behind a staging password; the password is asked for
- `[<path>] = '/'`: The path of the page, on the Site URL

## `kami:cache:clear`

Make every cached page and fragment stale, and delete the stored pages

## `kami:doctor`

Check that this environment can run Kami

- `[--strict]`: Fail on warnings too

## `kami:forms:deliver`

Deliver the Form Submissions whose notification failed or was never sent

## `kami:forms:prune`

Delete the Form Submissions older than their Form's retention

## `kami:install`

Install Kami, or bring it up to date after a deploy

- `[--email [EMAIL]]`: The first administrator's email, used while no User may manage Users
- `[--name [NAME]]`: The first administrator's name

## `kami:make:migration`

Write a migration bringing the kami_type_* tables in line with the declared Content Types

- `[<type>]`: A Content Type's handle or class, every declared type when left out

## `kami:make:type`

Start a Content Type: write its class into app/Content and print the lines to add elsewhere

- `[--global-set]`: One Entry with no URL, holding values shown across the Site
- `[--singleton]`: One Entry per Site, such as a home page
- `[--taxonomy]`: Terms classifying other types
- `<name>`: The class name, such as NewsItem

## `kami:media:prune`

Delete the Media files no longer served: former versions, removed presets, widths and formats, deleted items, interrupted writes

## `kami:media:warm`

Generate the Conversions of every Media item, or of those an Entry uses, skipping the files already written

- `[--entry [ENTRY]]`: Only the Media items this Entry uses, by its id
- `[--preset [PRESET]]`: Only these Image Presets; file for a document's or an SVG's own file

## `kami:sitemap`

Rebuild the sitemap when it is stale

## `kami:tick`

Run every overdue Scheduled task, in-process

## `kami:tick:url`

Generate a token for the URL a host's planner calls to run the Tick

## `kami:user:grant`

Give a Role to an existing User, found by email

- `<email>`: The User's email, in any letter case
- `<role>`: The handle of a Role declared in config/kami.php

## `kami:user:reset-mfa`

Clear the authenticator of a User, found by email

- `<email>`: The User's email, in any letter case
