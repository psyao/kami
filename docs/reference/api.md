## `Psyao\Kami\Forms\Form`

`abstract class`

A front form a site declares under `kami.forms`: its handle, Laravel rules whose keys are its fields, and what becomes of a Submission (ADR 0015).

- `public function handle(): string`: `ContactForm` → `contact`: the class name in snake_case, without a trailing `Form`. Used in the route, `form="…"` and `?sent=`.
- `final public function label(): string`: `kami-forms.{handle}.label`, or the humanised handle.
- `public function notification(Psyao\Kami\Forms\Submission $submission): Illuminate\Notifications\Notification`: What tells the site owner about a Submission: by default `SubmissionReceived`, a mail to `recipients()`. Each channel of its `via()`
- `public function recipients(): array`: The mail addresses a Submission is sent to.
- `public function replyTo(): ?string`: The field holding the visitor's mail address, put on `Reply-To`; `null` for none.
- `public function retention(): ?Carbon\CarbonInterval`: How long a Submission is kept: twelve months by default, `null` forever.

## `Psyao\Kami\Import\Import`

Each item gets a Legacy id, unique to its source; a replay skips an item whose payload is unchanged and rewrites one whose payload changed: the source wins. Kami deletes nothing: `finish()` reports the items a run did not see.

- `public function find(string $source, string $legacyId): ?Psyao\Kami\Content\Entry`: The Entry imported under this Legacy id, by this run or an earlier one; null when there is none or it is in the Trash, which a relation Field refuses as a target.

- `public function media(string $source, string $legacyId, string $path, array $values = [], ?Carbon\CarbonInterface $createdAt = NULL, ?Carbon\CarbonInterface $updatedAt = NULL): Psyao\Kami\Media\Media`: Imports one source file as a Media item, through `SaveMedia`, with its original dates: in one transaction, whole or not at all, its original deleted again if it fails. - `public static function start(string $label, ?string $site = NULL): Psyao\Kami\Import\Import`: Opens a run into a Site, the current one when `$site` is null. Until `finish()`, writes record no Audit event of their own: the run records one summary.

## `Psyao\Kami\Schema\ContentMigrator`

`final class`

What a migration calls to move data a schema change cannot express (ADR 0006). Each operation goes through the query builder, in batches but for `renameType`'s one update, with no JSON function, no model event and no `updated_at` change. None has a `down()`: going back is a new migration with the inverse operation.

- `public static function dropLocale(string $locale): void`: Destroys a Locale: its translations, its rows in every type's table, its references and its paths. The Entries stay. A Locale still declared is refused, as is the Shared `'*'`.

- `public static function makeTypeShared(string $type, string $keep, bool $discardOthers = false): void`: Keeps one Locale's translation as the shared one, for a type whose `$translatable` turned false. Field rows stay: `makeShared()` moves them, Field by Field.
- `public static function makeTypeTranslatable(string $type, string $locale): void`: Moves each shared translation to a Locale, for a type whose `$translatable` turned true. Field rows stay: `makeTranslatable()` moves them, Field by Field.
- `public static function renameField(string $type, string $from, string $to): void`: Renames a Field: its column and that column's index when it has one, else a relation Field's rows in `kami_references`.
- `public static function renameType(string $from, string $to): void`: Moves a type's Entries and its table to a new handle, with the index and foreign key names that follow the old one.
